# Release 04/06/2026 - v2.22.5

## Resumo

O arquivo final do coletor local passou a usar o numero da `OS` no nome sempre que esse contexto estiver disponivel, e o fluxo automatico do ERP agora limpa os arquivos temporarios do coletor ao terminar.

## O que mudou

- quando a coleta local tem contexto de `OS`, o JSON final passa a seguir o padrao:
  - `C:\JovemTechBenchCollector\inf_<numero_os>.json`
- o proprio executavel `JovemTechBenchCollector.exe`, ao receber `--warranty-os-number`, ja grava no nome final esperado;
- quando nao houver `OS`, o fallback continua:
  - `C:\JovemTechBenchCollector\last-snapshot.json`
- o backend do ERP agora envia o numero da `OS` para o coletor antes da leitura local;
- depois que a coleta local automatica termina com sucesso e o JSON e enriquecido com a `OS digital`, o sistema remove:
  - `C:\JovemTechBenchCollector\JovemTechBenchCollector.exe`
  - `C:\JovemTechBenchCollector\README.md`
- a pasta local passa a ficar com foco apenas no JSON final.

## Arquivos alterados

- `php -l app/Config/SystemRelease.php`

- execucao real de:
  - `JovemTechBenchCollector.exe --dry-run --no-prompt --no-save-config`
  - `JovemTechBenchCollector.exe --dry-run --no-prompt --no-save-config --warranty-os-number "OS260600001"`

## Observacao operacional

No fluxo automatico disparado pelo ERP, o JSON final permanece na pasta local e os binarios temporarios sao removidos. Em coletas tecnicas fora do ERP, o executavel continua disponivel para o operador porque a limpeza automatica depende do backend do sistema.
