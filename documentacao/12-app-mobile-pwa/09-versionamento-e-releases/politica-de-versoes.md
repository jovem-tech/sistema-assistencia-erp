# Politica de Versoes do App Mobile/PWA

## Regras gerais

- o app mobile/PWA possui ciclo de versao proprio;
- a linha do app nao precisa acompanhar a linha do ERP em cada release;
- qualquer mudanca de rota, autenticacao, API ou compatibilidade exige atualizacao deste hub.

## Linha atual

- versao documentada: `0.4.2`
- ERP minimo compativel: `2.11.5`

## Boas praticas

- registrar aqui somente mudancas confirmadas no fluxo mobile/PWA;
- manter a entrada do app alinhada com a rota `GET /atendimento-mobile`;
- atualizar o README do hub sempre que o destino de login do app mudar.
