# Release v2.19.6 - Competencia por mes/ano no Financeiro

Data: `01/06/2026`
Versao ERP: `2.19.6`
App/PWA compativel: `0.4.2`

## Resumo executivo

O formulario do modulo `Financeiro` passou a tratar a competencia de forma mais intuitiva para a operacao diaria:

- lancamentos manuais agora usam `Mes/ano de competencia`
- o backend salva internamente como `01/mm/aaaa`
- apenas receitas automaticas de `OS` preservam a `data cheia` de entrega

## O que mudou

1. `Novo lancamento` e `Editar lancamento` deixaram de expor um campo de data completa para a competencia manual.
2. O backend passou a aceitar `data_competencia_mes` no formato `YYYY-MM` e converter automaticamente para `data_competencia = YYYY-MM-01`.
3. Quando a competencia vier automaticamente de uma `OS`, o formulario mostra a data exata em modo somente leitura.
4. A listagem do `Financeiro`, o modal de detalhes e o relatorio operacional passaram a exibir `competencia` como `mes/ano` para lancamentos manuais, evitando confusao com dias tecnicos.

## Impacto funcional

- a `DRE` continua sendo mensal, mas agora a tela deixa isso explicito para a equipe
- o banco continua compativel com `DATE`
- a rastreabilidade exata das receitas automaticas de `OS` foi preservada
