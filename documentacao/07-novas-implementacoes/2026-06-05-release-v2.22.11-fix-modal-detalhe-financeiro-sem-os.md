# Release v2.22.11 - fix do modal de detalhe financeiro sem OS

Data: `05/06/2026`
ERP: `2.22.11`
App/PWA: `0.4.2`

## Objetivo

Corrigir a abertura do modal de detalhamento do `Financeiro` quando o titulo nao possui `OS` vinculada.

## O que mudou

- a partial do modal deixou de assumir que sempre existira um array de `osDetalhes`;
- quando a conta nao possui `OS`, o bloco de equipamento deixa de chamar o helper com valor nulo;
- o endpoint `GET /financeiro/detalhes/{id}` passou a responder JSON estruturado tambem em falhas internas de renderizacao;
- o frontend continua mostrando feedback amigavel sem quebrar o fluxo da tela.

## Motivacao operacional

Alguns lancamentos manuais e despesas avulsas nao possuem relacionamento com `OS`. Nesses casos, o modal precisava abrir apenas com o contexto financeiro do titulo.

Antes da correcao, a tentativa de montar o nome do equipamento com `osDetalhes = null` gerava erro no backend e impedia a abertura do modal.

## Arquivos principais alterados

- `app/Controllers/Financeiro.php`
- `app/Views/financeiro/partials/detail_modal_content.php`
- `app/Config/SystemRelease.php`

## Validacao executada

- `php -l app/Controllers/Financeiro.php`
- `php -l app/Views/financeiro/partials/detail_modal_content.php`
- `php -l app/Config/SystemRelease.php`
