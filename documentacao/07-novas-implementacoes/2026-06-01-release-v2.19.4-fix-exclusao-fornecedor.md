# Release v2.19.4 - Correcao do fluxo de exclusao com data-url

Data: `01/06/2026`
Versao ERP: `2.19.4`

## Resumo

Foi corrigido o fluxo de exclusao acionado pelos botoes da listagem de `Fornecedores`, que estava navegando para `/undefined` em vez de executar a rota real de exclusao.

## O que mudou

- o handler global `.btn-delete` agora aceita tanto `href` quanto `data-url`, mantendo compatibilidade entre modulos antigos e botoes renderizados como `<button>`;
- a confirmacao de exclusao desse fluxo central passou a usar `SweetAlert2` via `window.DSFeedback.confirm`;
- quando um botao de exclusao vier sem rota configurada, o sistema mostra feedback amigavel e registra erro tecnico no console em vez de navegar para uma URL quebrada;
- os botoes de exclusao de `Fornecedores` e `Funcionarios` passaram a enviar `data-nome` para mensagens mais claras na confirmacao.
