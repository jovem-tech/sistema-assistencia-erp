# Release v2.18.0 - Configuracoes Financeiras Estruturadas

Data: 01/06/2026

## Objetivo

Parar de depender de texto livre no modulo financeiro e criar uma base configuravel para:

- `categorias financeiras`
- `grupos DRE`
- `subgrupos DRE`
- navegacao financeira mais coerente na sidebar

## O que entrou na release

### 1. Novo submenu `Financas`

O sidebar passou a concentrar a navegacao financeira em:

- `Financas -> Financeiro`
- `Financas -> DRE Gerencial`
- `Financas -> Fluxo de Caixa`
- `Financas -> Configuracoes`

### 2. Tela `Configuracoes financeiras`

Foi criada a pagina:

- `GET /financeiro/configuracoes`

Ela centraliza o cadastro de:

- categorias financeiras
- grupos DRE
- subgrupos DRE

### 3. Dropdowns no lancamento financeiro

O formulario de `Novo lancamento` e `Editar lancamento` deixou de depender apenas de campo livre e passou a usar dropdowns para:

- `Categoria`
- `Grupo DRE`
- `Subgrupo DRE`

As categorias tambem podem sugerir automaticamente:

- grupo DRE padrao
- subgrupo DRE padrao
- impacto em DRE
- impacto em Caixa
- sugestao de `despesa fixa mensal na DRE`

### 4. Base de dados

Foram criadas as tabelas:

- `financeiro_categorias`
- `financeiro_dre_grupos`
- `financeiro_dre_subgrupos`

Migration:

- `2026-06-01-120000_CreateFinanceiroCatalogos.php`

## Impacto funcional

- o operador passa a escolher categorias e estrutura DRE por dropdown;
- o ERP ganha um ponto unico de governanca para o financeiro gerencial;
- a DRE e o fluxo de caixa continuam acessiveis pelo menu financeiro, sem depender do modulo geral de relatorios para a navegacao principal.
