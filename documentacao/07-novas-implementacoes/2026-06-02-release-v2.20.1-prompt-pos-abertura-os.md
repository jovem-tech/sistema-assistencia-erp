# Release v2.20.1 - Refinamento da Prompt Pos-Abertura da OS

Data: `02/06/2026`
Versao ERP: `2.20.1`
App/PWA compativel: `0.4.2`

## Resumo executivo

A prompt exibida logo apos criar uma nova OS foi refinada para reduzir atrito no balcao:

- `Enviar agora`
- `Gerar sem abrir WhatsApp`
- `Enviar depois`

Com isso, a equipe decide no mesmo passo se vai seguir para o envio, apenas abrir o PDF ou deixar a acao para outro momento.

## O que mudou

1. `app/Views/os/show.php` passou a usar uma prompt com tres opcoes claras em vez de um fluxo binario.
2. A escolha de `fotos de perfil` e `fotos de entrada` continua sendo feita na mesma janela.
3. Quando o operador escolhe `Gerar sem abrir WhatsApp`, o sistema abre diretamente a pre-visualizacao `A4` com os grupos de foto selecionados.
4. Quando o operador escolhe `Enviar agora`, o modal de WhatsApp continua sendo aberto com `template os_aberta`, formato `A4` e grupos de foto ja preconfigurados.
5. O estado de pre-visualizacao passou a carregar `photoGroups`, permitindo manter coerencia entre preview e envio.

## Impacto funcional

- menos cliques para quem so quer revisar ou imprimir o documento;
- mais clareza para a recepcao no momento de decidir entre gerar, enviar ou deixar para depois;
- maior consistencia entre as fotos escolhidas, a pre-visualizacao e o envio final.

## Arquivos principais envolvidos

- `app/Config/SystemRelease.php`
