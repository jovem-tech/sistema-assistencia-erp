# Release v2.21.0 - Desktop montado e agente de inventario

Data: 04/06/2026

## Objetivo

Melhorar o cadastro de `Desktop` no ERP e permitir complemento tecnico automatico de `Desktop` e `Notebook` quando o equipamento ligar na bancada.

## O que mudou

### 1. Novo perfil para Desktop

O tipo `Desktop` agora trabalha com dois modos:

- `Desktop de marca/OEM`
- `Desktop montado`

No modo `Desktop montado`, o cadastro deixa de depender de marca/modelo como referencia principal e passa a usar o resumo tecnico do equipamento.

### 2. Novos campos tecnicos em equipamentos

Foram adicionados ao cadastro:

- `desktop_modalidade`
- `gabinete_tipo`
- `gabinete_identificacao_status`
- `gabinete_observacao`
- `placa_mae`
- `chipset`
- `processador`
- `memoria_ram`
- `armazenamento`
- `placa_video`
- `fonte_alimentacao`
- `resumo_tecnico`
- `configuracao_status`
- `configuracao_origem`
- `configuracao_detectada_em`

### 3. Resumo tecnico automatico

O ERP agora monta um nome tecnico mais util para exibicao, por exemplo:

`Desktop montado | Mid Tower | H510 | Intel Core i5-10400 | 16 GB | SSD 480 GB`

Esse resumo passa a ser reaproveitado em:

- cadastro de equipamentos
- modal inline da OS
- ficha do equipamento
- listagem de OS
- visualizacao da OS
- impressao consolidada
- PDFs
- dashboard
- relatorios
- busca global
- resumo financeiro vinculado a OS

### 4. Guia para identificar gabinete

O formulario ganhou o botao `Como identificar?`, com apoio rapido para classificar:

- `Slim / SFF`
- `Mini Tower`
- `Mid Tower`
- `Full Tower`
- `Compacto / Cube`
- `Rack / Industrial`
- `Nao identificado / A confirmar`

### 5. Agente de inventario

Foi disponibilizado o script:

- `public/assets/agents/jovemtec-monitor-agent.ps1`

Ele pode ser executado na bancada para:

- provisionar o agente pela OS
- coletar inventario da maquina
- enviar snapshots para o ERP
- complementar automaticamente o cadastro do equipamento

Campos detectados pelo agente:

- fabricante
- modelo
- tipo do dispositivo
- tipo de chassi
- placa-mae
- chipset
- BIOS
- processador
- GPU
- memoria RAM
- armazenamento
- versao do Windows

### 6. Sincronizacao entre agente e equipamento

O endpoint `POST /api/v1/agents/check-in` agora:

- grava o payload bruto em `monitor_agent_snapshots`
- atualiza o ultimo estado em `monitor_agents`
- sincroniza os campos tecnicos do equipamento vinculado

Essa sincronizacao vale para:

- `Desktop`
- `Notebook`

## Impacto operacional

### Balcao

O operador pode registrar rapidamente:

- cliente
- tipo
- serie/IMEI
- fotos
- cor
- observacoes
- o que estiver visivel do desktop montado

### Bancada

Quando o equipamento ligar:

- a equipe pode completar manualmente os dados tecnicos
- ou executar o agente para acelerar memoria, chipset, processador e armazenamento

## Compatibilidade

- outros tipos de equipamento continuam com o fluxo tradicional
- `Desktop montado` ainda recebe `marca/modelo` padrao no backend para compatibilidade com o catalogo
- o nome mostrado para a equipe passa a respeitar `display_name` e `display_label`
