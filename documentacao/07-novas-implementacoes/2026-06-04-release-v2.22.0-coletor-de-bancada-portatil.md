# Release v2.22.0 - Coletor de bancada portatil

Data: 04/06/2026

## Objetivo

Entregar um coletor de bancada portatil para `Desktop` e `Notebook`, sem instalacao no computador do cliente, reutilizando a infraestrutura de `bootstrap` e `check-in` do agente de inventario ja existente no ERP.

## O que mudou

### 1. Projeto fonte do coletor em C#

Foi criado o projeto:

- `tools/bench-collector/JovemTech.BenchCollector/`

Responsabilidades:

- coletar inventario local no Windows via `WMI`;
- identificar `hostname`, `serie`, `fabricante`, `modelo`, `deviceType`, `chassisType`, `placa-mae`, `chipset`, `BIOS`, `CPU`, `GPU`, `RAM`, `armazenamento` e `Windows`;
- provisionar o agente pela `OS`;
- enviar `check-in` para o ERP.

### 2. Executavel portatil publicado

Foi padronizada a publicacao em:

- `public/assets/agents/bench-collector/win-x64/JovemTechBenchCollector.exe`
- `public/assets/agents/JovemTechBenchCollector-win-x64.zip`

Caracteristicas:

- roda sem instalacao;
- modo principal de uso: uma coleta unica por execucao;
- modo interativo por padrao;
- suporta `--continuous` para repeticao de check-ins;
- suporta `--dry-run` para coletar e mostrar os dados sem enviar ao ERP.

### 3. Script oficial de publicacao

Foi criado:

- `scripts/agents/publish-bench-collector.ps1`

Esse script:

- instala um SDK .NET local em `.tools/dotnet-sdk/` quando necessario;
- publica o executavel self-contained para `win-x64`;
- gera o pacote `.zip` pronto para distribuicao interna.

### 4. Ficha do equipamento orientada para o coletor

A tela de visualizacao do equipamento passou a priorizar:

- download do `Coletor de Bancada (.zip)`;
- instrucao de uso do `JovemTechBenchCollector.exe`;
- exibicao do `InstallationId` sugerido e da `OS` sugerida;
- comando em `PowerShell` apenas como fallback tecnico.

## Fluxo operacional recomendado

1. a recepcao faz o cadastro rapido no balcao;
2. a bancada liga o equipamento;
3. a equipe baixa e extrai `JovemTechBenchCollector-win-x64.zip`;
4. executa `JovemTechBenchCollector.exe`;
5. confirma `ERP`, `email` e `OS`;
6. o coletor faz `bootstrap` e `check-in`;
7. o ERP sincroniza os dados tecnicos do equipamento.
