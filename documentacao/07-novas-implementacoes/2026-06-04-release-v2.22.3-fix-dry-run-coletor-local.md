# Release v2.22.3 - Fix do dry-run no coletor local

Data: `04/06/2026`

## Problema corrigido

Ao clicar em `Buscar do agente (C:\)`, o ERP executava o `JovemTechBenchCollector.exe` em `--dry-run`.

Mesmo nesse modo local, o executavel ainda criava o cliente HTTP do ERP antes de verificar que a execucao era somente local. Quando a `URL` do ERP nao estava preenchida, o processo podia falhar com:

- `Invalid URI: The format of the URI could not be determined.`

## Ajuste aplicado

O `Program.cs` do coletor foi reorganizado para:

1. coletar o inventario;
2. salvar o snapshot local;
3. encerrar normalmente em `--dry-run`;
4. criar `ErpAgentClient` apenas quando realmente for fazer `bootstrap` e `check-in`.

## Arquivo principal alterado

- `tools/bench-collector/JovemTech.BenchCollector/Program.cs`

## Validacao executada

- rebuild do coletor com `scripts/agents/publish-bench-collector.ps1`
- execucao real de `JovemTechBenchCollector.exe --dry-run --no-prompt --no-save-config`
- confirmacao de geracao do snapshot local sem erro de `Invalid URI`
