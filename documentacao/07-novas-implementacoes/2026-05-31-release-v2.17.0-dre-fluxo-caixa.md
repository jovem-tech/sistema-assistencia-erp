# Release v2.17.0 - DRE e Fluxo de Caixa

Data: 31/05/2026

## Objetivo

Entregar o primeiro baseline do financeiro gerencial dentro do ERP, separando de forma explicita:

- `movimentacao financeira operacional`
- `DRE` por competencia
- `fluxo de caixa` realizado e projetado

## O que entrou na release

### 1. Base de dados

Migration:
- `2026-05-31-120000_AddGerencialFieldsToFinanceiro.php`

Novos campos em `financeiro`:
- `data_competencia`
- `origem_tipo`
- `origem_id`
- `grupo_dre`
- `subgrupo_dre`
- `impacta_dre`
- `impacta_fluxo_caixa`

Backfill inicial aplicado:
- receitas de OS -> `Receita Operacional`
- compras emergenciais de pecas -> `Custo Direto (OS)`
- receitas manuais -> `Outras Receitas`
- despesas manuais -> `Despesas Operacionais`

### 2. Regras de negocio

O `FinanceiroModel` passou a:

- inferir classificacao gerencial automaticamente quando o usuario nao preencher
- tratar `data_competencia` como base da DRE
- tratar `data_pagamento` como base do caixa realizado
- tratar `data_vencimento` como base do caixa projetado

### 3. Novas telas e relatorios

Foram entregues:

- painel `Financeiro` com classificacao gerencial visivel
- formulario de lancamento com campos de `DRE` e `Caixa`
- relatorio `Movimentacoes Financeiras`
- relatorio `DRE Gerencial`
- relatorio `Fluxo de Caixa`

### 4. Ajustes de nomenclatura

Para evitar ambiguidade contábil, o sistema deixou de chamar `caixa realizado` de `Lucro` nos pontos principais de leitura operacional.

Mudancas visiveis:
- painel `Financeiro`
- relatorio operacional financeiro
- `Dashboard`

### 5. Documentacao e ajuda contextual

Foram atualizados:

- manuais do usuario
- banco de dados
- rotas internas
- roadmap financeiro
- historico oficial de versoes

A documentacao contextual tambem ganhou aliases para abrir corretamente os manuais certos a partir dos botoes de ajuda.

## Limitacoes ainda conhecidas

Esta release entrega o baseline, mas ainda nao cobre:

- baixa parcial
- multiplos movimentos para o mesmo titulo
- contas financeiras separadas por caixa/banco
- conciliacao bancaria
- desdobramento formal entre `titulo financeiro` e `movimento de caixa`
